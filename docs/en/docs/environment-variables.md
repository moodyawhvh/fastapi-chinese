# 环境变量 { #environment-variables }

**环境变量**(也称为 **env var**)是一种存在于 Python 代码之外、保存在操作系统中的值,你的应用和其他程序都可以读取它。

FastAPI 应用通常用环境变量来做配置,比如数据库 URL、邮箱凭据和密钥(secret key)。

在[设置和环境变量](advanced/settings.md)一章中,你会学到如何用它们进行应用配置。

## 了解更多 { #learn-more }

阅读[环境变量指南](https://tiangolo.com/guides/environment-variables/),获取详细的跨平台讲解,包括如何创建和读取环境变量,以及 `PATH` 环境变量是如何工作的。
